1. 🟢 입출력 + 변수

prompt / console / let
  • prompt() : 사용자가 입력한 값을 문자열로 반환
  • confirm() : 확인/취소 → Boolean
  • console.log() : 콘솔 출력
  • alert() : 알림창
  • document.write() : HTML 화면 출력
let name = prompt('이름을 입력하세요');
console.log(`안녕하세요~ ${name}님 즐거운 하루 되세요~!`);
키워드재선언재할당
var가능가능
let불가능가능
const불가능불가능
개인 필기 보완: const는 값이 바뀌면 안 되는 데이터를 담을 때 사용합니다. 수업 필기에서는 변하지 않는 함수 등을 변수에 담을 때도 const를 사용하는 형태를 기록했습니다.

2. 🔵 자료형 + 형변환

typeof / Number / parseInt

숫자형, 문자열, Boolean, undefined, null, 배열 [], 객체 {}를 배웠고 typeof()로 타입 확인.

시험 핵심: prompt 결과는 문자열. 숫자 계산이면 먼저 형변환.
let num1 = parseInt(prompt('첫 번째 숫자'));
let num2 = parseInt(prompt('두 번째 숫자'));
console.log(num1 + num2);
목적코드
숫자Number()
정수parseInt()
실수parseFloat()
문자열String() / toString()
소수점 자리toFixed(n)

3. 🟠 연산자

% / === / && / ? :

산술: + - * / % / 비교: ==, ===, !=, !== / 논리: !, &&, || / 삼항: 조건 ? 참 : 거짓

let num = parseInt(prompt('숫자 입력'));
console.log(num % 2 === 0 ? `${num}은 짝수입니다.` : `${num}은 홀수입니다.`);
증감연산자 ++num은 먼저 증가, num++은 현재 값 먼저 사용 후 증가.

5. 🔁 반복문

while / for / break
let num = 1;
while (num < 11) {
    console.log(num);
    num += 1;
}
for (let i = 1; i <= 10; i++) {
    console.log(i);
}
무한반복 체크: while 안에서 값이 바뀌는지, while(true)라면 break 조건이 있는지 확인.

6. 📦 배열 Array

push / pop / splice / length
let array = [];
array[0] = 1;
array.push(2);
array.pop();
기능코드
길이array.length
수정array[2] = 7
마지막 추가push()
마지막 삭제pop()
중간 삭제splice(인덱스, 개수)
포함 확인includes()
인덱스 찾기indexOf()
일부 복사slice(시작, 끝)
개인 필기 보완: 배열을 반복할 때 조건을 i < array.length로 두는 이유는 배열의 데이터가 추가·삭제되어 길이가 바뀔 수 있기 때문입니다.
for (let i = 0; i < array.length; i++) {
    console.log(array[i]);
}

7. 🧩 함수

function / return / =>
function sum(num1, num2) {
    return num1 + num2;
}
console.log(sum(3, 10));
const func = (num1, num2) => {
    console.log(num1 + num2);
};

매개변수 1개면 괄호 생략 가능. 한 줄 반환이면 중괄호와 return 생략 가능.

함수 vs 메서드: 개인 필기 기준으로 함수는 독립된 코드 블록이고, 메서드(method)는 배열처럼 어떤 대상에 종속되어 있는 함수입니다. 예: array.push()에서 push()는 배열에 종속된 메서드.

9. 🔎 DOM — HTML 요소 찾기

getElement... / querySelector
기준코드
iddocument.getElementById('id')
classdocument.getElementsByClassName('class')
tagdocument.getElementsByTagName('li')
namedocument.getElementsByName('name')
CSS 선택자 1개document.querySelector('#id')
CSS 선택자 전체document.querySelectorAll('li')
유사배열 주의: getElementsByClassName(), getElementsByTagName() 결과는 HTMLCollection, getElementsByName(), querySelectorAll() 결과는 NodeList 형태로 여러 요소를 담습니다. 개인 필기에서는 이런 값을 배열처럼 인덱스로 접근하지만 배열 관련 함수를 그대로 사용할 수 없는 유사배열로 정리했습니다. 하나만 필요해도 [0]이 필요한지 확인하세요.
let list = document.querySelectorAll('li');
for (let i = 0; i < list.length; i++) {
    console.log(list[i].innerText);
}

10. ✏️ DOM — 내용 변경

innerText / innerHTML / value

innerText = 글자만 / innerHTML = 태그 + 글자.

let title = document.getElementById('tit');
title.innerText = '텍스트 변경';
title.innerHTML = '<a href="#">링크 생성</a>';
let div = document.getElementById('divTag');
div.innerHTML += '<h1>DOM활용하기!</h1>';
innerText로 읽은 숫자는 문자열이므로 계산 전에 parseInt() 확인.

13. 🌐 fetch — 데이터 통신

fetch / then / json / catch
let movieUrl = `API주소`;

fetch(movieUrl)
    .then((res) => res.json())
    .then((res) => {
        console.log(res);
    })
    .catch((error) => {
        console.log(error);
    });
수업 흐름: 버튼 찾기 → click 이벤트 → prompt 날짜 → URL에 ${date} → fetch → res.json() → 필요한 배열 → for 반복 → table 문자열 누적 → div.innerHTML → catch
let table = `<table>
    <tr>
        <th>순위</th>
        <th>영화명</th>
        <th>개봉일</th>
    </tr>`;

for (let i = 0; i < movieList.length; i++) {
    table += `
        <tr>
            <td>${movieList[i].rank}</td>
            <td>${movieList[i].movieNm}</td>
            <td>${movieList[i].openDt}</td>
        </tr>`;
}

table += `</table>`;
document.getElementsByTagName('div')[0].innerHTML = table;
