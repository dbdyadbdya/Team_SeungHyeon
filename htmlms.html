6. 📊 테이블

table / tr / th / td / colspan / rowspan
태그/속성역할
table표 공간 선언
caption표 제목
tr한 행
th제목 셀
td데이터 셀
colspan좌우 열 병합
rowspan위아래 행 병합
<table border="1">
  <caption>메뉴판</caption>
  <tr>
    <th colspan="2">메뉴</th>
  </tr>
  <tr>
    <td>아메리카노</td>
    <td rowspan="2">3500</td>
  </tr>
  <tr>
    <td>카페라떼</td>
  </tr>
</table>
시험 실수: colspan/rowspan으로 병합한 뒤 겹치는 td 또는 th는 제거하거나 주석 처리합니다.

7. 📝 Form 태그

form / input / select / textarea
항목핵심
method="get"URL에 내용이 보일 수 있음
method="post"URL 노출 없이 전송, 로그인/회원가입 등
action전송할 위치
name입력값 구분 이름
placeholder입력 안내문구
autofocus페이지 열릴 때 자동 커서
value기본값
readonly읽기 전용
maxlength최대 글자 수
<form method="get" action="#">
  ID <input type="text" name="id" placeholder="아이디 입력">
  PW <input type="password" name="pw" maxlength="10">
  <input type="submit" value="전송하기">
  <input type="reset">
</form>

선택형

축구 <input type="checkbox" name="hobby" value="soccer">
남성 <input type="radio" name="gender" value="man">
여성 <input type="radio" name="gender" value="woman">
radio 핵심: 같은 질문에서 하나만 선택하게 하려면 name을 같게 맞춥니다.

select / textarea

<select>
  <option>A형</option>
  <option>B형</option>
  <option>O형</option>
  <option>AB형</option>
</select>

<textarea cols="30" rows="5"></textarea>

8. 🧪 회원가입 폼 실습 패턴

table + form

수업 실습은 form 안에 table을 넣고, 단계별 제목 행은 th + colspan으로 묶는 구조입니다.

<form method="get" action="#">
  <table width="400" border="1">
    <tr bgcolor="gray" height="50" align="center">
      <th colspan="2">step 1 : 아이디/비번 입력</th>
    </tr>
    <tr>
      <td align="center">아이디</td>
      <td><input type="text" name="id"></td>
    </tr>
  </table>
</form>

submit/reset이 안 먹음form 태그 안에 있는지
