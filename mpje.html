오후 · Flask 연결

app.py에서 CSV를 읽고 HTML에 전달한다.

from flask import Flask, render_template import pandas as pd app = Flask(__name__) signals = pd.read_csv("result/signals.csv") @app.route("/") def index(): data = signals.to_dict("records") return render_template("index.html", signals=data) @app.route("/detail/<int:signal_id>") def detail(signal_id): row = signals[signals["signal_id"] == signal_id] if row.empty: return "Signal not found", 404 signal = row.iloc[0].to_dict() return render_template("detail.html", signal=signal) if __name__ == "__main__": app.run(debug=True)

터미널에서 실행:

python app.py

브라우저에서 http://127.0.0.1:5000 접속.

Front 연결

templates/index.html에서는 Jinja 문법으로 Signal 카드들을 반복 출력한다.

<div class="signal-list"> {% for signal in signals %} <div class="signal-card"> <span>{{ signal.category }} / {{ signal.signal_type }}</span> <h3>{{ signal.title }}</h3> <p>{{ signal.summary }}</p> <a href="/detail/{{ signal.signal_id }}">분석 보기</a> </div> {% endfor %} </div>

5. 데이터 분석 — 비전공자 기준으로 어떤 순서로 보면 되는지

① 원본 데이터 열기

제일 먼저 “무슨 데이터인지” 확인한다. 바로 그래프부터 그리지 않는다.

import pandas as pd df = pd.read_csv("../data/raw/파일명.csv") display(df.head(10)) print("크기:", df.shape) print("컬럼:", df.columns.tolist()) df.info()

여기서 날짜, 지역, 값, 장르, 평점 등 “분석에 쓸 컬럼”을 표시해둔다.

② 결측치와 이상한 값 찾기
display(df.isnull().sum()) display(df.describe(include="all"))

빈 값이 있으면 무조건 지우는 게 아니라, 해당 컬럼이 분석에 필요한지 먼저 판단한다.

③ 날짜/숫자 자료형 정리
df["날짜"] = pd.to_datetime(df["날짜"], errors="coerce") df["숫자컬럼"] = pd.to_numeric(df["숫자컬럼"], errors="coerce")

errors="coerce"는 변환이 안 되는 값을 NaN으로 바꿔서 오류로 프로그램이 멈추지 않게 한다.

④ 그룹별 평균/합계/개수 보기
# 지역별 평균 result = df.groupby("지역")["값"].mean() # 지역별 건수 count = df.groupby("지역").size() # 월별 평균 monthly = df.groupby(df["날짜"].dt.to_period("M"))["값"].mean()
⑤ 변화율 만들기
df["변화율"] = df["값"].pct_change() * 100

이 값이 갑자기 커진 곳이 CHANGE SIGNAL 후보가 된다. 단, 데이터 순서를 날짜순으로 정렬한 뒤 계산해야 한다.

⑥ Signal 후보가 나왔을 때 검증
  • 결측치나 잘못된 행 때문에 튄 값은 아닌가?
  • 표본이 너무 적은 것은 아닌가?
  • 전월 하나만 비교한 것인가, 최근 평균과도 비교했는가?
  • 다른 지역/팀/콘텐츠와 비교해도 특이한가?
  • 인과관계라고 말하지 않고 “취재 후보”라고 표현했는가?

7. Flask — HTML과 분석 결과를 연결하는 역할

Flask는 Python에서 읽은 데이터를 HTML에 전달하고, 브라우저 주소에 따라 어떤 페이지를 보여줄지 결정한다.

최소 라우팅

/ → 메인 /category/economy → 사회·경제 /category/kcontents → K-Contents /category/sports → 스포츠 /detail/1 → Signal 1 상세

이미지 경로

웹에서 쓸 그래프는 가능하면 static/images/ 또는 static/charts/에 둔다. Flask는 static 폴더를 웹용 파일 폴더로 인식한다.

<img src="{{ url_for('static', filename='images/signal_01.png') }}" alt="분석 그래프">

8. API / AI — 어디까지 해야 하는가

외부 API

목적: K-Contents의 외부 관심도/반응 데이터를 보충.

첫날에는 “실제로 값을 받아오는지”만 확인하고, 성공하면 필요한 필드만 CSV로 저장해서 분석한다.

AI

목적: Signal을 찾는 것이 아니라, 이미 발견된 Signal을 바탕으로 취재 질문을 생성.

AI 결과는 반드시 “추가 취재 필요”라는 안내를 붙인다.

API Key 금지: 실제 Key를 app.py에 적은 채 GitHub에 push하지 않는다. .env에 넣고 .gitignore에 .env를 추가한다.
