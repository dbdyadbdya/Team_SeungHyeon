🚀 1. JS 시작 / 입출력

script 태그

<script>
console.log('오늘 JS 첫 시간.');
</script>

🔎 개발자 도구

입력 / 출력

함수역할

alert()팝업 메시지 출력
document.write()화면에 출력하며 HTML 태그 사용 가능

✨ 템플릿 리터럴은 백틱(`)을 사용하고 변수는 ${변수} 형태로 삽입합니다.

🔁 6. 반복문

while

let num=1;
while(num<11){
  console.log(num);
  num++;
}

무한 반복 + break

while(true){
  if(종료조건){
    break;
  }
}

for문

초기화→조건식→실행→작업 후 처리
for(let i=100; i>=1; i--){
  console.log(i);
}
💡 누적 실습에서는 sum += num 형태의 복합대입 연산자와 break를 함께 사용했습니다.

⚙️ 8. 함수 Function

일반 함수

function sum(a,b){
  return a+b;
}
console.log(sum(3,10));

화살표 함수

const sum = (a,b) => a+b;
const greet = name => `제 이름은 ${name}`;
📌 선언부의 값은 매개변수, 호출할 때 전달하는 실제 값은 인자(인수)입니다. 매개변수 1개면 () 생략 가능, 한 줄 반환식이면 {}와 return도 생략할 수 있습니다.

🎨 12. JS로 CSS 제어

  blueBox.style.marginLeft='100px';
  greenBox.style.marginLeft='200px';
});

여러 요소 반복 변경

let div = document.querySelectorAll('div');
radius.addEventListener('click',()=>{
  for(let i=0; i<div.length; i++){
    div[i].style.borderTopRightRadius='50px';
    div[i].style.borderBottomLeftRadius='50px';
  }
});
📌 CSS의 background-color 같은 속성은 JS에서 backgroundColor처럼 camelCase로 작성합니다.

🌐 13. Fetch / 영화 데이터 통신

날짜 입력→API URL→fetch()→json()→반복문→innerHTML

Promise 처리

fetch(movieUrl)
 .then(res => res.json())
 .then(res => {
   let movieList =
     res.boxOfficeResult.dailyBoxOfficeList;
 })
 .catch(error => console.error(error));

핵심

fetch는 JS 내장 기능이며 URL을 요청하고, 응답을 JSON으로 변환한 뒤 then에서 처리하고 catch에서 오류를 처리합니다.

테이블 출력

let table = `<table>
<tr><th>순위</th><th>영화명</th><th>개봉일</th></tr>`;

for(let i=0; i<movieList.length; i++){
  table += `
  <tr>
    <td>${movieList[i].rank}</td>
    <td>${movieList[i].movieNm}</td>
    <td>${movieList[i].openDt}</td>
  </tr>`;
}
table += '</table>';
document.getElementById('abc').innerHTML = table;
🔐 정리본에서는 실습에 포함된 API 키 값은 노출하지 않고 구조만 남겼습니다.
