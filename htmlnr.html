1. 🔧 Ready (준비하기)

기본 문서 구조

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width,
                   initial-scale=1.0">
    <title>Document</title>
</head>
<body>

</body>
</html>

⚙️ 준비 단계 체크리스트

  • VS Code 실행
  • ! + Enter : 문서 형식 자동 생성
  • Alt + L + O : Live Server 실행
  • Ctrl + / : 주석 처리
  • Alt + Shift + ↑ / ↓ : 위/아래 복사
  • Alt + 클릭 : 다중 커서

br : 줄바꿈

2. ✨ 강조 태그

태그설명
<b>시각적으로 굵게 표시
<strong>의미적으로 중요한 내용 강조
<mark>배경색으로 강조
<sup>위첨자
<sub>아래첨자
<b>굵게</b>

<mark>배경색 강조</mark>

2<sup>3</sup>
H<sub>2</sub>O
💡 태그 안에 다른 태그를 넣는 형태를 태그 중첩이라고 합니다.

3. 📋 리스트 태그

◆ ul (정돈되지 않은 리스트)

type : disc(기본), circle, square
<ul type="square">
  <li>html</li>
  <li>css</li>
  <li>js</li>
</ul>

◆ ol (정돈된 리스트)

type : 1(기본), A, a, I, i
<ol type="I">
  <li>등원하기</li>
  <li>QR찍기</li>
  <li>수업듣기</li>
</ol>
📌 ul과 ol 모두 실제 데이터는 li 태그 안에 작성합니다.

4. 🖼️ 이미지 삽입

필수 속성 : src

외부 이미지 주소 사용
<img src="https://example.com/image.jpg">
내부 이미지 상대 경로 사용
<img src="../img/11.jpg"
     width="1000px">

📁 경로 정리

경로의미
./현재 위치
../상위 폴더
/최상위 기준
💡 이미지가 안 뜨면 파일명 / 확장자 / 폴더 위치부터 확인하세요.

5. 🔗 a 태그 (링크)

필수 속성 : href

<a href="https://www.naver.com">
  네이버로 이동
</a>

이미지에 링크 걸기

<a href="./document/ex04이미지.html">
  <img src="./img/11.jpg">
</a>
📎 이미지를 a 태그 안에 넣으면 이미지 클릭 시 이동 가능합니다.

6. 🧾 테이블 태그

태그설명
<table>표 전체 영역
<caption>표 제목
<tr>행(Row)
<th>제목 셀
<td>일반 셀

병합 속성

rowspan : 위/아래 병합
colspan : 좌/우 병합
<th colspan="2">메뉴</th>

<td rowspan="2">3,500</td>
⚠️ row = 행 = 세로 병합 / col = 열 = 가로 병합

7. 🏆 Form 태그

Form 속성

method
get : URL에 내용 표시
post : URL에 내용 직접 노출 X

action
데이터를 전달할 서버 주소

텍스트 입력

⌨️ input type="text"
🔒 input type="password"
📅 input type="date"
🎨 input type="color"
📁 input type="file"

선택 입력

☑️ checkbox : 중복 선택 가능
◉ radio : 같은 name에서 하나만 선택
▾ select + option : 드롭다운 선택

주요 input 속성

속성설명
name입력한 값을 구분하기 위한 이름
placeholder입력 전 안내 문구
autofocus페이지 실행 시 자동 커서
value기본값 / 전송값 지정
readonly사용자가 수정할 수 없는 읽기 전용
maxlength최대 입력 글자 수 제한
ID <input type="text"
   name="id"
   placeholder="아이디를 입력하세요."
   autofocus>

PW <input type="password"
   name="pw"
   maxlength="10">
남성 <input type="radio"
 name="gender" value="man">

여성 <input type="radio"
 name="gender" value="woman">

<textarea cols="30" rows="5">
</textarea>
