1. 🧾 CSS 적용 방식

style / link
수업에서 확인된 방식: HTML 안의 <style> 태그에 CSS를 작성하거나, 외부 CSS 파일을 <link rel="stylesheet">로 연결하는 방식이 등장했습니다.
<style>
    h1 {
        color: green;
    }
</style>
<link rel="stylesheet" href="./ex11_position.css">

2. 🎯 기본 선택자 + 우선순위

* / tag / .class / #id / !important
종류문법수업 필기 점수특징
전체 선택자*0점모든 요소
태그 선택자h11점같은 태그 전체
클래스 선택자.dinner10점중복 사용 가능, 재사용성 높음
아이디 선택자#tuna100점한 문서에서 고유 요소용
인라인 스타일style=""1000점태그 안에 직접 작성
!importantcolor:black !important;최고 우선다른 규칙보다 강하게 적용
* {
    color: rgb(34, 151, 230);
}

.dinner {
    color: darkorchid;
}

#tuna {
    color: black !important;
}
시험 함정: 같은 요소에 여러 CSS가 겹치면 선택자 우선순위를 먼저 확인하세요.

3. 🌳 계층 + 형제 선택자

공백 / > / ~ / + / nth-child
관계기호뜻예시
자손띄어쓰기기준 요소 안쪽 모든 하위 관계div span
자식>바로 아래 자식ol > span
후행 형제~뒤쪽에 있는 같은 형제들li ~ li
근접 형제+바로 다음 형제 하나li + li
div span {
    color: palevioletred;
}

ol > span {
    color: darkorchid;
}

li ~ li {
    color: green;
}

li + li {
    color: cornflowerblue;
}
nth-child()는 부모의 모든 자식 순서를 기준으로 n번째 요소를 확인합니다.
li:nth-child(4) + li {
    color: brown;
}

4. 🖱️ 반응 선택자 + 그룹 선택자

:hover / :active / ,
선택자언제 적용?
:hover마우스를 올렸을 때
:active마우스로 클릭하고 있는 순간
,여러 선택자에 같은 스타일을 적용
h1:hover {
    color: gold;
}

h2:active {
    color: blueviolet;
}

h2, h3 {
    color: cadetblue;
}

5. 🔤 폰트 속성

font-size / weight / style / family
속성의미
font-size글자 크기
font-weight글자 굵기, 100~900 / 700은 bold 수준
font-style글자 스타일
font-family폰트 종류
p {
    font-size: 40px;
    font-weight: 200;
    font-style: oblique;
    font-family: 'OngleipEoyeonce';
}
@font-face {
    font-family: 'OngleipEoyeonce';
    src: url('폰트주소') format('woff');
    font-weight: normal;
    font-display: swap;
}
수업 파일에는 외부 웹폰트를 @font-face로 불러오는 예시가 포함되어 있습니다.

6. 🧱 display

block / inline / none
값특징수업 예시 태그
block가로 한 줄 영역 차지, width/height 설정 가능div, p, table
inline내용만큼만 영역 차지, width/height 설정 불가img, span, a, b
none화면에서 요소를 보이지 않게 처리질문/답 실습
.answer {
    display: none;
}

.question:hover + .answer {
    display: inline;
    color: cadetblue;
}
시험 패턴: “평소에는 숨기고 마우스를 올리면 옆의 답을 보여라” → display:none + :hover + 형제선택자.

7. 📏 margin — 바깥 여백

margin / margin-left
margin: border를 기준으로 바깥쪽 여백.
값 개수적용 순서
1개상하좌우 모두 동일
2개첫 번째 = 위/아래, 두 번째 = 좌/우
3개위 / 좌우 / 아래
4개위 → 오른쪽 → 아래 → 왼쪽 (시계 방향)
div {
    margin: 10px 20px 30px 40px;
}

#box2 {
    margin-left: 101px;
}

8. 📦 padding + border

padding / border / radius
padding: border를 기준으로 안쪽 여백. 값 적용 순서는 margin과 동일하게 사용합니다.
#box {
    width: 100px;
    height: 100px;
    border: solid 20px rgb(161, 215, 238);
    padding-right: 50px;
}
border 관련 속성예시
두께border-width: 3px;
색상border-color: cadetblue;
모양border-style: dotted;
한 줄 작성border: 3px cadetblue dotted;
둥근 모서리border-radius: 50px;
원 만들기: 수업 신호등 실습처럼 width:100px; height:100px; border-radius:50px; 형태를 사용했습니다.

9. 📐 box-sizing

content-box / border-box
값내가 적은 width가 의미하는 범위결과
content-box내용(content) 너비만padding/border가 추가되면 전체 크기가 커짐
border-box내용 + padding + border까지 포함padding/border를 줘도 설정한 전체 너비 안에 포함
.cb {
    box-sizing: content-box;
}

.bb {
    box-sizing: border-box;
}
시험 핵심: “padding과 border를 줘도 전체 도형 크기가 커지지 않게 하라” → box-sizing: border-box;

10. 🧭 Flex

display:flex / direction / justify / align
Flex 개념: 레이아웃 배치용 기능. 부모 = container, 자식 = item.
속성역할
display:flex부모에 Flex 적용
flex-direction메인 축 방향 설정
justify-content메인 축 기준 정렬
align-items서브 축 기준 정렬
flex-basis자식 요소가 차지할 기본 비율/크기
.container {
    display: flex;
    flex-direction: row;
    justify-content: center;
    align-items: center;
}

.item {
    flex-basis: 15%;
}

#center {
    flex-basis: 70%;
}
가운데 정렬 문제: 부모에 display:flex → 가로 중앙 justify-content:center → 세로 중앙 align-items:center.

메뉴바 수업 패턴

.container {
    height: 100px;
    display: flex;
}

.box1, .box3 {
    flex-basis: 15%;
}

.box2 {
    flex-basis: 70%;
    display: flex;
    justify-content: center;
    align-items: center;
}

.box2 > a:hover {
    color: white;
    background-color: black;
}

11. 📍 position

static / relative / absolute / fixed / sticky
값기준/특징
static기본값. 위치 속성 비활성화
relative원래 있던 위치를 기준으로 이동
absolute위치 속성이 static이 아닌 부모를 기준으로 배치
fixed부모·스크롤을 무시하고 화면에 고정
sticky부모 안에서 스크롤하다 특정 위치에 도달하면 고정
#relative {
    position: relative;
    top: 50px;
    left: 50px;
}

#absolute {
    position: absolute;
    top: 50px;
    left: 50px;
}

#fixed {
    position: fixed;
    bottom: 0;
    right: 0;
}

#sticky {
    position: sticky;
    top: 50px;
}
absolute 체크: 부모의 position이 static이면 원하는 부모를 기준으로 잡지 못할 수 있습니다. 수업 필기 핵심은 “static이 아닌 부모”입니다.
시험 문장 → 코드: “스크롤해도 우측 하단에 계속 보여라” → position:fixed; bottom:0; right:0;

🧯 오류 찾기 비법

시험 직전 체크
증상확인할 것
CSS가 안 먹음선택자 이름(. / # / 태그)이 맞는가?
다른 색이 적용됨선택자 우선순위 / 인라인 / !important가 있는가?
자식만 고르려 했는데 하위 전체가 선택됨공백 대신 >가 필요한가?
바로 옆 형제만 선택하려는데 여러 개 선택됨~ 대신 +가 필요한가?
hover 시 답이 안 보임.question:hover + .answer 구조가 실제 HTML 순서와 맞는가?
width/height가 inline에 안 먹음inline 기본 특성인지 확인
박스 크기가 예상보다 커짐content-box인지 border-box인지 확인
Flex 중앙정렬 안 됨부모에 display:flex가 있는가?
top/left가 static에서 안 움직임position이 static인지 확인
absolute 기준이 이상함부모 position이 static 아닌지 확인

🏆 문제 유형별 복붙 레시피

시험장에서 바로 쓰기

① 클래스 하나로 여러 요소 꾸미기

.menu {
    color: darkorchid;
}

② 마우스를 올리면 다음 요소 보이기

.answer {
    display: none;
}

.question:hover + .answer {
    display: inline;
}

③ 상하좌우 여백 한 번에

.box {
    margin: 10px 20px 30px 40px;
    padding: 10px 20px;
}

④ 크기 유지되는 박스

.box {
    width: 500px;
    padding: 20px;
    border: 20px solid gray;
    box-sizing: border-box;
}

⑤ 부모 안에서 완전 중앙정렬

.parent {
    display: flex;
    justify-content: center;
    align-items: center;
}

⑥ 화면 우측 하단 고정 버튼

.topBtn {
    position: fixed;
    right: 0;
    bottom: 0;
}

⑦ 특정 부모 기준 absolute

.parent {
    position: relative;
}

.child {
    position: absolute;
    top: 50px;
    left: 50px;
}
