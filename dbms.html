3. 🧾 SQL 기본

Structured Query Language
SQL: 데이터베이스를 위한 표준 질의 언어.
분류역할예시
QUERY검색/조회SELECT

수업 규칙: SQL은 대소문자를 구분하지 않고, 띄어쓰기/줄바꿈은 명령 수행에 영향을 주지 않으며, 문장 끝에는 세미콜론(;)을 붙입니다.

4. 🔢 SQL 문장 실행 순서

FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY
순서절역할
1FROM데이터를 가져올 테이블
2WHERE원하는 행 조건
3GROUP BY특정 컬럼 기준 그룹화
4HAVING그룹화 상태 조건
5SELECT출력할 컬럼
6ORDER BY정렬
시험 함정: SELECT가 WHERE보다 나중에 실행되므로, 수업에서는 WHERE절에서 SELECT 별칭을 사용할 수 없다고 정리했습니다.

5. 🔎 SELECT

* / 원하는 컬럼
SELECT *
  FROM EMPLOYEES;
SELECT EMPLOYEE_ID, FIRST_NAME, HIRE_DATE
  FROM EMPLOYEES;
시험 팁: 컬럼명을 잘 모르겠으면 먼저 SELECT * FROM 테이블;로 전체를 확인한 뒤 문제를 푸는 수업 방식.

6. 🧹 DISTINCT — 중복 제거

DISTINCT
SELECT DISTINCT DEPARTMENT_ID
  FROM EMPLOYEES;
SELECT DISTINCT JOB_ID, DEPARTMENT_ID
  FROM EMPLOYEES;
컬럼이 2개면 각 컬럼 따로가 아니라 두 컬럼 조합의 중복을 제거.

7. 🏷️ 별칭 + 산술 연산

AS / + - * /
SELECT SALARY AS "급여",
       SALARY*12 AS "연봉"
  FROM EMPLOYEES;
SELECT FIRST_NAME,
       HIRE_DATE + 1 AS "계약일"
  FROM EMPLOYEES;
수업 파일에서는 별칭에 AS를 쓰거나 생략하는 여러 형태를 확인했습니다.

8. ⭕ NULL 기본

0/공백과 다름
NULL: 값이 완전히 비어 있거나 아직 정의되지 않은 상태. 0이나 공백과 다름.
  • NULL과 산술 연산 → 결과 NULL
  • NULL과 일반 비교 연산 → FALSE

9. 🎯 WHERE — 조건 지정

WHERE 컬럼 조건 값
SELECT *
  FROM EMPLOYEES
 WHERE JOB_ID = 'IT_PROG';
SELECT FIRST_NAME, LAST_NAME
  FROM EMPLOYEES
 WHERE EMPLOYEE_ID = 105;
SQL 비교는 등호 1개: =

10. ⚖️ 비교 / 등가 비교 연산자

> >= < <= = != <> ^=
의미기호
비교>, >=, <, <=
같다=
같지 않다!=, <>, ^=, NOT =
SELECT FIRST_NAME, SALARY
  FROM EMPLOYEES
 WHERE SALARY <= 5000;
SELECT FIRST_NAME, JOB_ID
  FROM EMPLOYEES
 WHERE JOB_ID <> 'FI_ACCOUNT';
개인 노션 필기: 성능 차이는 기본적으로 없고 <>를 많이 사용한다고 정리.

11. 🧠 AND / OR

AND 우선
연산자뜻
AND모든 조건이 TRUE
OR하나의 조건만 TRUE여도 TRUE
SELECT EMPLOYEE_ID, FIRST_NAME
  FROM EMPLOYEES
 WHERE DEPARTMENT_ID = 90
   AND SALARY >= 5000;
SELECT FIRST_NAME, EMPLOYEE_ID, SALARY*12 AS ANNSAL
  FROM EMPLOYEES
 WHERE (DEPARTMENT_ID = 100 OR DEPARTMENT_ID = 50)
   AND SALARY*12 >= 10000;
시험 핵심: AND가 OR보다 우선. OR을 먼저 묶고 싶으면 소괄호 사용.

12. 🕳️ IS NULL / IS NOT NULL

NULL 전용 비교
SELECT FIRST_NAME, PHONE_NUMBER
  FROM EMPLOYEES
 WHERE PHONE_NUMBER IS NULL;
SELECT FIRST_NAME, PHONE_NUMBER
  FROM EMPLOYEES
 WHERE PHONE_NUMBER IS NOT NULL;
틀린 형태: = NULL, != NULL, <> NULL 사용 금지.

13. 📚 IN / NOT IN

= + OR / <> + AND
IN: 여러 개의 OR 조건을 한 번에. NOT IN: 여러 값을 제외.
SELECT *
  FROM EMPLOYEES
 WHERE DEPARTMENT_ID IN (30, 50, 90);
SELECT FIRST_NAME, MANAGER_ID
  FROM EMPLOYEES
 WHERE MANAGER_ID NOT IN (145,146,147,148,149);
NOT IN + NULL 주의: 수업 필기에서는 괄호 안에 NULL이 들어가면 비교가 FALSE가 되고 AND 구조 때문에 결과가 나오지 않는 점을 강조했습니다.

14. 📏 BETWEEN

범위 조건
SELECT FIRST_NAME, SALARY
  FROM EMPLOYEES
 WHERE SALARY BETWEEN 10000 AND 19999;
SELECT FIRST_NAME, HIRE_DATE
  FROM EMPLOYEES
 WHERE HIRE_DATE BETWEEN '05/01/01' AND '05/12/31';

15. 🔤 LIKE + 와일드카드

% / _
패턴뜻
'S%'S로 시작
'%s's로 끝
'%s%'s 포함
'1__'1로 시작하는 3글자
SELECT FIRST_NAME
  FROM EMPLOYEES
 WHERE FIRST_NAME LIKE '%s%'
    OR FIRST_NAME LIKE '%S%';

16. 🔡 문자 함수

UPPER / LOWER / LENGTH / SUBSTR / REPLACE / CONCAT / TRIM
함수역할
UPPER대문자로 변환
LOWER소문자로 변환
LENGTH문자열 길이
SUBSTR문자열 일부 추출
REPLACE문자열 대체/제거
CONCAT문자열 2개 합치기
TRIM특정 문자열 제거
SELECT FIRST_NAME, UPPER(FIRST_NAME),
       EMAIL, LOWER(EMAIL)
  FROM EMPLOYEES;
SELECT HIRE_DATE AS 입사일,
       SUBSTR(HIRE_DATE,1,2) AS 연도,
       SUBSTR(HIRE_DATE,4,2) AS 월,
       SUBSTR(HIRE_DATE,7) AS 일
  FROM EMPLOYEES;
SELECT '입사일은 ' || HIRE_DATE || '입니다.'
  FROM EMPLOYEES;

17. 🔢 숫자 함수

MOD / ROUND / TRUNC / DUAL
SELECT MOD(15,6),
       MOD(14,2)
  FROM DUAL;
SELECT ROUND(15.65),
       TRUNC(15.65),
       ROUND(15.65,1),
       TRUNC(15.65,1)
  FROM DUAL;
DUAL: 임시 연산이나 함수 결과를 확인할 때 사용하는 더미 테이블로 수업에서 설명.

18. 📅 날짜 함수

SYSDATE / ADD_MONTHS
SELECT SYSDATE AS 현재시각,
       SYSDATE+1 AS 하루더함,
       SYSDATE+1/24 AS 한시간더함,
       SYSDATE+1/24/60 AS 일분더함,
       SYSDATE+1/24/60/60 AS 일초더함
  FROM DUAL;
SELECT SYSDATE AS 현재,
       ADD_MONTHS(SYSDATE,1) AS 한달뒤,
       ADD_MONTHS(SYSDATE,-1) AS 한달전
  FROM DUAL;

19. 🔁 형변환 함수

TO_CHAR / TO_NUMBER / TO_DATE
SELECT TO_CHAR(SYSDATE, 'YY/MM/DD/DAY')
  FROM DUAL;
SELECT TO_NUMBER('1') + 1
  FROM DUAL;
SELECT TO_DATE('20230504', 'YYYY/MM/DD')
  FROM DUAL;
수업 필기: 명시적 형변환과 암시적 형변환을 구분했고, 우선순위는 날짜형 > 숫자형 > 문자형으로 정리.

20. 🧯 NULL 함수

NVL / NVL2
SELECT COMMISSION_PCT,
       NVL(COMMISSION_PCT,0)
  FROM EMPLOYEES;
SELECT MANAGER_ID,
       NVL2(MANAGER_ID,'직원','관리자')
  FROM EMPLOYEES;
함수형식
NVLNVL(대상, NULL일 때 바꿀 값)
NVL2NVL2(대상, NULL 아닐 때, NULL일 때)

21. 🔀 DECODE — 분기 함수

검사값에 따라 결과 변경
SELECT FIRST_NAME, DEPARTMENT_ID, SALARY,
       DECODE(DEPARTMENT_ID,
              100, SALARY*2,
              90, SALARY*1.9,
              80, SALARY*1.8,
              SALARY) AS 성과급
  FROM EMPLOYEES;

22. 📊 그룹 함수

SUM / COUNT / MAX / MIN / AVG
SELECT SUM(SALARY) AS 급여총합,
       COUNT(SALARY) AS 급여개수,
       MAX(SALARY) AS 최대급여,
       MIN(SALARY) AS 최소급여,
       ROUND(AVG(SALARY)) AS 급여평균
  FROM EMPLOYEES;

🧯 오류 찾기 비법

시험 직전 체크
증상확인
SQL 실행이 안 됨세미콜론(;)이 있는가?
조건식이 이상함SQL 비교는 = 하나인지 확인
WHERE에서 별칭 오류실행 순서상 WHERE가 SELECT보다 먼저임
NULL 검색 안 됨= NULL 대신 IS NULL 사용
NOT IN 결과가 0건목록에 NULL이 섞였는지 확인
AND/OR 결과가 예상과 다름AND 우선순위와 괄호 확인
문자 검색 안 됨LIKE 패턴과 %, _ 위치 확인
함수 테스트가 필요함DUAL로 먼저 확인
NULL 때문에 계산이 깨짐NVL/NVL2 필요 여부 확인
