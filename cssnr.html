1. 🎯 CSS 적용하기 / 선택자 우선순위

기본 구조

선택자 {
    속성: 값;
}
📌 CSS는 선택자로 대상을 정하고, 중괄호 안에 스타일 속성과 값을 작성합니다.

선택자 예시

* {
    color: red;
}

.dinner {
    color: green;
}

#tuna {
    color: black !important;
}

선택자 우선순위 점수

전체 선택자0*
태그 선택자1h1
클래스 선택자10.dinner
아이디 선택자100#tuna
인라인 스타일1000style=""
최고 우선!!important
💡 클래스 값은 중복 사용이 가능해 재사용성이 높고, 아이디 값은 한 문서에서 하나의 고유 요소에 사용하는 방식으로 배웠습니다.

2. 🧭 CSS 선택자

선택자기호 / 형식설명
자식 선택자>기준 요소의 바로 아래 자식 선택
자손 선택자띄어쓰기기준 요소 아래의 자손 요소 선택
형제 후행 선택자~기준 요소 뒤에 있는 형제 요소들 선택
근접 형제 선택자+기준 요소 바로 다음에 붙은 형제 선택
nth-child():nth-child(n)부모의 n번째 자식이면서 태그가 일치하는 요소 선택
반응 선택자:hover, :active마우스 올림 / 클릭 시 반응
그룹 선택자,여러 선택자에 같은 스타일 적용
/* 자손 */
div span {
    color: blue;
}

/* 자식 */
ol > span {
    color: red;
}

/* 형제 */
li ~ li {
    color: chocolate;
}

/* 근접 형제 */
li + li {
    color: blueviolet;
}
li:nth-child(4) + li {
    color: chartreuse;
}

h1:hover {
    color: red;
}

h2:active {
    color: blue;
}

h2, h3 {
    color: brown;
}

3. 🔤 Font 속성

속성설명
font-size폰트 크기
font-weight폰트 굵기. 100~900 숫자를 사용하며 700은 bold
font-style폰트 스타일 변경
font-family폰트 종류 지정
p {
    font-size: 50px;
    font-weight: 200;
    font-style: inherit;
    font-family: 'DearFromsol';
}
@font-face {
    font-family: 'DearFromsol';
    src: url('폰트주소') format('woff2');
    font-weight: 400;
    font-display: swap;
}
📝 수업에서는 @font-face를 이용해 외부 폰트를 불러와 적용했습니다.

4. 🖥️ Display

⬛ block

예: div, p, table

가로 한 줄 영역을 차지하며 width / height 설정 가능

▬ inline

예: img, span, a, b

컨텐츠만큼 영역을 차지하며 수업에서는 width / height 설정이 불가능한 값으로 정리

🙈 none

화면에 출력된 요소를 보이지 않게 처리

hover + 인접 선택자 실습

.answer {
    display: none;
}

.question:hover + .answer {
    color: rgb(87, 168, 211);
    display: inline;
}
💡 질문 위에 마우스를 올리면 바로 옆에 있는 답변의 display가 다시 inline으로 바뀌어 보이게 만드는 실습입니다.

5. ↔️ Margin

Margin = border 바깥 여백

값 개수적용 방식
1개위 · 오른쪽 · 아래 · 왼쪽 모두 동일
2개위/아래 · 좌/우
3개위 · 좌/우 · 아래
4개시계 방향으로 순차 적용
#box2 {
    margin-left: 100px;
}

#box3 {
    margin-left: 200px;
}

#box4 {
    margin-left: 300px;
}
📌 margin-left처럼 방향을 직접 지정해서 원하는 위치에만 적용할 수도 있습니다.

6. 📦 Padding

Padding = border 안쪽 여백

수업에서는 padding의 값 적용 방식이 margin과 동일하며, 원하는 방향을 지정해 사용할 수 있다고 정리했습니다.
#box {
    width: 100px;
    height: 100px;
    border: solid 20px black;
    padding-right: 50px;
}
#box2 {
    padding-right: 100px;
}

#box3 {
    padding-right: 200px;
}

#box4 {
    padding-right: 300px;
}
🧱 padding을 추가하면 content와 border 사이의 내부 공간이 커집니다.

7. 🧱 Box-sizing

content-box

내가 설정한 width = content 영역의 너비

padding과 border가 추가되면 그만큼 전체 도형이 커짐 
.cb {
    box-sizing: content-box;
}

border-box

내가 설정한 width = border 안쪽까지 포함한 전체 너비

내용 + padding + border = 설정한 width 
.bb {
    box-sizing: border-box;
}
💡 padding과 border를 추가해도 전체 도형의 크기가 커지지 않게 하고 싶을 때 수업에서는 box-sizing: border-box를 사용하는 것으로 정리했습니다. fileciteturn0file0L85-L96

9. 🧩 Flex

Flex 기본 개념

  • flex는 레이아웃 배치 전용 기능
  • 부모 요소 = container
  • 자식 요소 = item
  • 부모에 display: flex 적용
  • 적용 시 기본적으로 가로 배치

주요 속성

속성역할
flex-direction배치 방향 설정
justify-content메인 축 기준 정렬
align-items서브 축 기준 정렬
flex-basis자식 요소의 기준 크기 지정
.container {
    display: flex;
    flex-direction: row;
    justify-content: center;
    align-items: center;
}

.item {
    flex-basis: 15%;
}

#center {
    flex-basis: 70%;
}
📌 수업 노트에서는 row를 메인 축(가로), column을 서브 축(세로)로 두고 정렬을 설명했습니다. fileciteturn0file0L224-L236

10. 🧭 Flex 실습 — 메뉴바 만들기

왼쪽 영역

box1
flex-basis: 15%

가운데 메뉴

box2
flex-basis: 70%
메뉴 · 베스트 · 뉴스

오른쪽 영역

box3
flex-basis: 15%
로그인 · 회원가입
SMHRD 15%→ 메뉴 / 베스트 / 뉴스 70%→ 로그인 / 회원가입 15% 
.container {
    height: 100px;
    display: flex;
}

.box2 {
    display: flex;
    justify-content: center;
    align-items: center;
    flex-basis: 70%;
}
a {
    text-decoration: none;
}

.box2 > a:hover,
.box3 > a:hover {
    color: white;
    background-color: black;
}

11. 📍 Position

값기준 / 특징
static기본값. 위치 속성이 비활성화
relative원래 있던 위치를 기준으로 이동
absoluteposition 값이 static이 아닌 부모를 기준으로 배치
fixed부모와 스크롤을 무시하고 화면 기준으로 고정
sticky부모 영역 안에서 특정 위치에 도달하면 고정
#relative {
    position: relative;
    top: 20px;
    left: 20px;
}

#absolute {
    position: absolute;
    top: 60px;
    left: 30px;
}
#fixed {
    position: fixed;
    bottom: 0px;
    right: 0px;
}

#sticky {
    position: sticky;
    top: 50px;
    left: 100px;
}
📌 sticky는 헤더나 사이드바처럼 스크롤 중 계속 보이게 하는 영역에 사용할 수 있으며, 항상 고정되는 것이 아니라 부모 안에서 특정 위치에 도달한 뒤 고정되는 방식으로 수업에서 정리했습니다. fileciteturn0file0L455-L465
