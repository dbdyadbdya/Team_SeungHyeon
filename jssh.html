Ch 1. 인라인(Inline) 이벤트 바인딩 방식

HTML 태그 내부에 onclick="" 속성을 직접 작성하여 함수를 실행시키는 1단계 기초 방식입니다.

  • 특징: HTML 요소에 자바스크립트 함수 호출 구문이 직접 결합됩니다.
  • 주의: 호출 시 반드시 함수 이름 뒤에 소괄호 ()를 붙여야 동작합니다.
원본 실습 코드
<!-- 인라인 방식: 소괄호() 필수 작성 -->
<button onclick="show()">클릭!</button>

<script>
function show() {
    alert('인라인 이벤트 클릭!');
}
</script>

Ch 2. 프로퍼티(Property) 이벤트 바인딩 방식

DOM 객체를 탐색하여 자바스크립트 코드 내에서 onclick 속성에 함수를 할당하는 방식입니다.

★ 시험 핵심 포인트: 함수 할당 시 show2()처럼 소괄호를 붙이면 클릭 시점이 아니라 페이지가 로드될 때 함수가 즉시 실행됩니다. 소괄호 없이 show2 형태(함수 이름만)로 지정해야 합니다.
원본 실습 코드
<button id="p_event">프로퍼티 클릭!</button>

<script>
let p_event = document.getElementById('p_event');

function show2() {
    alert('프로퍼티 이벤트 클릭!');
}

// [주의] 소괄호를 붙이면 로딩되자마자 실행됨 (show2() 금지)
p_event.onclick = show2; // 소괄호를 떼고 정의만 할당!
</script>

Ch 3. addEventListener 표준 이벤트 등록 방식

표준 방식으로, 동일한 요소에 여러 개의 이벤트를 중복으로 부여할 수 있어 실무에서 99% 사용됩니다.

원본 실습 코드
<button class="btn">표준 이벤트 클릭!</button>

<script>
let btn = document.getElementsByClassName('btn')[0];

btn.addEventListener('click', () => {
    alert('addEventListener 이벤트 클릭!');
});
</script>

Ch 4. 이벤트 객체(e)와 e.target 타겟 추출

이벤트가 발동될 때 생성되는 이벤트 객체 e와 사건이 터진 원인 요소를 가리키는 e.target 활용법입니다.

  • e: 생성된 이벤트에 대한 상세 정보 보고서 객체
  • e.target: 사건이 발생한 HTML 요소 그 자체를 지목
  • e.target.innerText: 클릭한 대상 태그 안의 텍스트 추출
원본 실습 코드
<h4 id="h4Tag">확인용</h4>

<script>
let h4 = document.getElementById('h4Tag');

h4.addEventListener('click', (e) => {
    console.log(e.target);           // 클릭된 
 요소 출력
    console.log(e.target.innerText); // "확인용" 텍스트 추출
});
</script>

Ch 5. keyup 이벤트 & 실시간 데이터 바인딩

키보드 눌렀다 떼는 keyup 이벤트로 <input> 입력값을 실시간 출력하는 원리입니다.

★ 핵심: <input> 요소의 입력 데이터값을 가지고 올 때는 innerText가 아닌 .value 속성을 사용합니다.
원본 실습 코드
<input type="text" id="inputTxt">
<p id="container"></p>

<script>
let inputTxt = document.getElementById('inputTxt');

inputTxt.addEventListener('keyup', () => {
    let container = document.getElementById('container');
    // input 요소의 실시간 값은 value로 읽어옴
    container.innerText = inputTxt.value;
});
</script>

Ch 6. DOM 접근 및 스타일 동적 제어 (CamelCase)

자바스크립트에서 요소명.style.속성 = 값 형태로 직접 CSS 스타일을 조작합니다.

  • CSS의 하이픈(-) 속성은 카멜 표기법으로 변경 (예: margin-left → marginLeft)
  • 대입하는 값은 수치 단위가 포함된 문자열 형태여야 함 ('100px')
원본 실습 코드
<div id="blueBox" style="width:100px; height:100px; background:blue;"></div>
<button class="move">이동하기!</button>

<script>
let blue = document.getElementById('blueBox');
let move = document.getElementsByClassName('move')[0];

move.addEventListener('click', () => {
    blue.style.marginLeft = '100px'; // 하이픈 제거 후 낙타표기법 적용
});
</script>

Ch 7. 다중 요소를 위한 querySelectorAll & for 반복문

querySelectorAll로 가져온 NodeList(유사 배열)를 for 문으로 순회하여 일괄 처리합니다.

원본 실습 코드
<div></div><div></div><div></div>

<script>
// 문서 안의 모든 div 요소를 NodeList(유사 배열)로 수집
let divList = document.querySelectorAll('div');

// 반복문 순회 (인덱스 초기화 0)
for(let i = 0; i < divList.length; i++) {
    console.log(divList[i]);
}
</script>

Ch 8. 복합 스타일 제어 (모서리 둥글게 일괄 적용)

버튼 클릭 시 divList 배열 요소 전체의 대각선 모서리를 동적으로 변경하는 예제입니다.

원본 실습 코드
<button class="radius">둥글게!</button>

<script>
let radius = document.getElementsByClassName('radius')[0];
let divList = document.querySelectorAll('div');

radius.addEventListener('click', () => {
    for(let i = 0; i < divList.length; i++) {
        // 상단 우측, 하단 좌측 모서리 동글게 변경
        divList[i].style.borderTopRightRadius = "50%";
        divList[i].style.borderBottomLeftRadius = '50%';
    }
});
</script>

Ch 9. fetch API 기본 비동기 네트워크 요청

자바스크립트에 내장되어 별도 설치 없이 URL로 비동기 통신을 요청하는 기본 구조입니다.

원본 실습 코드
<script>
let apiKey = 'e87048b654a2fbf134b83affc81ee7de';
let date = '20240101';
let movieUrl = `https://kobis.or.kr/kobisopenapi/webservice/rest/boxoffice/searchDailyBoxOfficeList.json?key=${apiKey}&targetDt=${date}`;

// fetch 사용 시 요청 URL 적용
fetch(movieUrl)
    .then((res) => res.json()) // 응답 데이터를 JSON 객체로 파싱
    .then((res) => {
        console.log(res);
    });
</script>

Ch 10. 백틱(``) 템플릿 리터럴과 동적 Table 생성

문자열 누적 연산자(+=)와 백틱 변수 삽입(${})을 이용해 HTML <table> 구조를 완성하는 기법입니다.

원본 실습 코드
<script>
let table = '';
table += `<table>
            <tr>
                <th>순위</th>
                <th>영화명</th>
                <th>개봉일</th>
            </tr>`;

// 반복문을 순회하며 행(tr) 누적
for(let i = 0; i < movieList.length; i++){
    table += `
    <tr>
        <td>${movieList[i].rank}</td>
        <td>${movieList[i].movieNm}</td>
        <td>${movieList[i].openDt}</td>
    </tr>`;
}
table += `</table>`;
</script>

Ch 11. 응답 데이터 innerHTML 동적 주입

완성된 문자열 형태의 HTML 표 태그를 DOM 요소의 innerHTML 속성에 주입하여 화면에 렌더링합니다.

원본 실습 코드
<div id="resultDiv"></div>

<script>
// 태그와 텍스트를 동시에 적용하는 innerHTML
let movieDiv = document.getElementsByTagName('div')[0];
movieDiv.innerHTML = table; // div에 완성된 표 출력
</script>

Ch 12. fetch catch 예외 예외 처리 (Error Handling)

네트워크 오류나 요청 실패 시 애플리케이션이 멈추지 않도록 에러를 캐치하여 출력합니다.

원본 실습 코드
<script>
fetch(movieUrl)
    .then((res) => res.json())
    .then((res) => {
        // 정상 로직 실행
    })
    // 에러 발생시 예외 처리
    .catch((error) => {
        console.error(error);
    });
</script>

Ch 13. [응용 문제 1] 박스 이동 및 모서리 제어 풀이

요구사항: [이동하기!] 버튼 누르면 박스를 계단식 연출하고, [둥글게!] 누르면 전체 모서리를 변경하는 종합 실습 코드입니다.

응용 정답 풀이 코드
let red = document.getElementById('redBox');
let blue = document.getElementById('blueBox');
let green = document.getElementById('greenBox');
let gray = document.getElementById('grayBox');

let move = document.getElementsByClassName('move')[0];
let radius = document.getElementsByClassName('radius')[0];

move.addEventListener('click', () => {
    blue.style.marginLeft = '100px';
    green.style.marginLeft = '200px';
    gray.style.marginLeft = '300px';
});

let divList = document.querySelectorAll('div');

radius.addEventListener('click', () => {
    for(let i = 0; i < divList.length; i++) {
        divList[i].style.borderTopRightRadius = "50%";
        divList[i].style.borderBottomLeftRadius = '50%';
    }
});

Ch 14. [응용 문제 2] 영화 박스오피스 동적 표 출력 풀이

요구사항: 버튼을 누르면 prompt로 날짜를 받아 kobis API 데이터를 조회하고, 이를 동적 table로 구성하여 출력하시오.

응용 정답 풀이 코드
<button>순위보기</button>
<br><br>
<div></div>

<script>
let btn = document.getElementsByTagName('button')[0];

btn.addEventListener('click', () => {
    let date = prompt('날짜를 입력하세요.', 'YYYYMMDD');
    let apiKey = 'e87048b654a2fbf134b83affc81ee7de';
    let movieUrl = `https://kobis.or.kr/kobisopenapi/webservice/rest/boxoffice/searchDailyBoxOfficeList.json?key=${apiKey}&targetDt=${date}`;

    fetch(movieUrl)
        .then((res) => res.json())
        .then((res) => {
            let movieList = res.boxOfficeResult.dailyBoxOfficeList;
            let table = '';
            table += `<table border="1">
                        <tr>
                            <th>순위</th>
                            <th>영화명</th>
                            <th>개봉일</th>
                        </tr>`;

            for(let i = 0; i < movieList.length; i++) {
                table += `
                <tr>
                    <td>${movieList[i].rank}</td>
                    <td>${movieList[i].movieNm}</td>
                    <td>${movieList[i].openDt}</td>
                </tr>`;
            }
            table += `</table>`;
            
            let movieDiv = document.getElementsByTagName('div')[0];
            movieDiv.innerHTML = table;
        })
        .catch((error) => console.error(error));
});
</script>
