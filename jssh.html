🚨 시험 함정 모음

시험 직전 O/X처럼 빠르게 점검하세요.
1. prompt() 입력값은 숫자다? ❌
String이다. 숫자 계산 전 Number()/parseInt() 등을 사용.
2. indexOf()에서 못 찾으면 0이다? ❌
못 찾으면 -1.
3. slice(0, 3)은 0~3까지다? ❌
3은 포함하지 않음. 0,1,2.
4. for문에서 i <= array.length가 기본이다? ❌
보통 i < array.length. 마지막 인덱스는 length-1.
5. onclick = show()가 클릭 때 실행 예약이다? ❌
()가 붙으면 대입 시점에 실행. onclick = show.
6. addEventListener('onclick', ...)가 맞다? ❌
'click'처럼 on을 빼고 작성.
7. input.innerText로 입력값을 읽는다? ❌
폼 요소 입력값은 .value.
8. querySelector()가 같은 요소를 전부 가져온다? ❌
첫 번째 요소 1개. 전부는 querySelectorAll().
9. getElementsByClassName()에 바로 innerText를 쓴다? ❌
HTMLCollection이므로 요소를 하나 선택해야 함.
10. const add=(a,b)=>{a+b}가 값을 반환한다? ❌
중괄호를 쓰면 return 필요.
11. switch의 break는 없어도 된다? ❌
없으면 아래 case까지 실행될 수 있음.
12. switch('0')에서 case 0이 실행된다? ❌
문자열 '0'과 숫자 0은 다름.
13. fetch() 직후 API 배열을 바로 사용할 수 있다? ❌
비동기 결과는 then 등에서 처리.
14. toFixed(2)의 결과는 Number다? ❌
String을 반환.
15. JS CSS에 margin-left를 그대로 쓴다? ❌
JS에서는 marginLeft.
16. style.marginLeft = 100이면 끝이다? ❌
보통 '100px'처럼 단위를 포함.
17. JS는 대소문자를 구분하지 않는다? ❌
대소문자를 엄격하게 구분.
18. typeof null은 'null'이다? ❌
typeof null → 'object'.
19. 화살표 함수 매개변수 2개도 () 생략 가능? ❌
2개 이상이면 () 필요.
20. innerHTML +=는 단순 문자열 덧붙이기와 완전히 같다? ⚠️
DOM 재구성 측면에서 반복 사용 시 주의.
